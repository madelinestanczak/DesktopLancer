
# Desktop Lancer
This is a little desktop Lancer pet I made in about 30 minutes to go with my DELTARUNE themed desktop. This is a Windows Forms app, and thus is designed for Windows.

## Usage
Simply open the executable and you'll have your very own desktop Lancer! When dragged, a red background appears- this is so you can reposition him with ease.
